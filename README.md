# Five Seconds to Explain the Glass

A house cat's one-sentence defence after knocking a glass off the table,
delivered in five seconds, with zero remorse.

## How it works

`main.py` writes a single deterministic sentence (133 characters) to
`/output/entry.txt`. No input files, no network, no secrets.

Run it:

```sh
python3 main.py
```

## The sentence

> That glass sat in my sunbeam all morning without once saying thank you,
> so I evicted it to the floor, where ungrateful things belong.
